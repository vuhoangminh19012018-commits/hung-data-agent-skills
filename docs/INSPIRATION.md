# Inspiration and provenance

This repository is an original, project-specific synthesis. It is inspired by public patterns from:

- Anthropic Agent Skills: small skill folders, `SKILL.md`, progressive disclosure.
- obra/superpowers: inspect/plan/test/debug/verify discipline for coding agents.
- mattpocock/skills: small composable skills and explicit shared project language.

No third-party skill file is vendored here. Review upstream licenses before copying any upstream implementation into this repository.
