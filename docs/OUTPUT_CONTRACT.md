# Agent Completion Report Contract

When finishing a coding/data task, report in this order:

1. **Result** — one sentence describing what now works.
2. **Changed** — files/modules changed and why.
3. **Verification** — exact tests/checks run and result counts.
4. **Data impact** — for mapping changes: records affected, mapping-quality delta, false-positive/false-negative observations if measured.
5. **Git** — branch/HEAD if relevant, and whether working tree is clean or has expected changes.
6. **Remaining risk** — only concrete unresolved items.

Never say "done", "fixed", "all good", or equivalent without fresh verification evidence from this task.
